# docs — all documentation and every figure

Each document is listed with what it covers, so you can pick one without opening it. The
root [README](../README.md) summarises the first three and links here.

## Start here

| Document | What it covers |
|---|---|
| **[DATASET_DOCUMENTATION.md](DATASET_DOCUMENTATION.md)** | How the dataset is organised, all 35 metadata columns, the splits, the cohorts, and example images before and after preprocessing. The place to start if you want to use the data |
| **[PREPROCESSING_AND_IMAGING.md](PREPROCESSING_AND_IMAGING.md)** | What a DCE-MRI study is and why the RGB channel assignment follows from it; every preprocessing step with the measurement that decided it; the interventions that were rejected; the patient-level data-leakage lesson with citations; and the cohort confound |
| **[RESULTS.md](RESULTS.md)** | Centralised against federated as an equivalence claim, the heterogeneity result, the communication finding, and how all of it compares with the published literature |
