# results — every run that was kept

Nothing here is deleted. Superseded runs stay because a failed experiment is only useful
if you can say what preceded it.

| Folder | What it holds |
|---|---|
| `classifier/` | The classifier phase: 21 runs across 13 architectures and 5 data configurations, the run table `all_runs_pod.csv`, and the checkpoints that were retained. This phase chose the configuration the federated campaign then held fixed. |
| `federated/` | The dissertation campaign: 13 experiments, `test01_centralized` through `test13_fedprox_sizematched`, plus `final_summary/` and `_ablations/`. |

## What each experiment folder contains

| File | What it is |
|---|---|
| `test_metrics.json` | macro-AUC, balanced accuracy, per-class AUC / precision / recall / F1, the confusion matrix and the trivial baseline |
| `predictions_test.csv` | One row per test patient — 268 rows |
| `sites/rounds.csv` | Per-round, per-site training and validation metrics across all 30 rounds |
| `sites/train.log` | The training log of every hospital |
| `job.json` | Job id, submission and completion times, algorithm, mu, client count, status |
| `global_model.pt` | The selected global model. Not in version control — 43 MB each |

## final_summary

Generated by `src/scripts/build_final_summary.py`, and the place to start.

| Path | What it is |
|---|---|
| `summary.{csv,json,md,pdf,xlsx}` | All 13 experiments in one table |
| `comparisons/` | Eight paired comparison tables, each isolating one factor |
| `tables/` | Nine LaTeX tables ready for the dissertation |
| `figures/` | Cross-experiment figures: metric bars, ROC overlay, heatmap, round evolution |
| `experiments/<name>/figures/` | Per-experiment confusion matrix, ROC and PR curves |
| `per_client_metrics.csv` | The one global model evaluated on each hospital's own validation patients |

## Before quoting any number

The noise floor is **0.067 macro-AUC** and the trivial accuracy baseline is **0.5112**.
Every experiment is a single run at seed 42. Differences below the noise floor are
reported as *no difference detected*. See [the results document](../docs/RESULTS.md).
