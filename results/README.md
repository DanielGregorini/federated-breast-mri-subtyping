# results

Where every run lands. Three folders, one per kind of run.

| Folder | What it holds |
|---|---|
| [`thesis/`](thesis/README.md) | The thirteen experiments the dissertation reports, plus the summary built from them. Frozen. |
| [`classifier/`](classifier/README.md) | Centralised runs from `notebooks/04_train_centralized.ipynb`, one auto-numbered folder each. |
| [`federated/`](federated/README.md) | Federated campaigns you collect yourself, one folder per experiment. |

Run folders are not version controlled. Only the READMEs and the frozen record under
`thesis/` are.
