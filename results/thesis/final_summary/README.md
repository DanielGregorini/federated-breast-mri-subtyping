# final_summary

Every table and figure that compares the experiments against each other, built in one
pass from the per-patient predictions each run left behind.

Generated by `deployment/code/scripts/build_final_summary.py`. It overwrites this folder, and it
reads nothing back, so it is safe to rerun at any time.

Status: 13 of 13 experiments present.

## What is in here

| Path | What it is |
|---|---|
| `summary.csv` | one row per experiment, the main table |
| `summary.md` | the same numbers as a readable report |
| `summary.json` | everything nested, including the curve points |
| `summary.xlsx` | every table as its own sheet |
| `summary.pdf` | the tables and figures as one printable document |
| `manifest.json` | which experiments were found and which were missing |
| `per_client_metrics.csv` | one row per experiment and hospital |
| `comparisons/` | one CSV per pairwise comparison |
| `figures/` | figures spanning every experiment |
| `experiments/<name>/` | metrics, curves and figures for one experiment |
| `cohort/` | how the data was divided, independent of any run |
| `tables/` | the same tables as LaTeX blocks |

## The columns

Every metric is computed per patient. The model predicts each 2-D slice, and the slice
probabilities belonging to one patient are averaged into one prediction before
anything is scored.

| Column | What it is |
|---|---|
| `macro_auc` | one-vs-rest ROC AUC, averaged over the 3 classes |
| `auc_<class>` | one-vs-rest AUC for that class alone |
| `accuracy` | fraction of patients whose top class is correct |
| `trivial_baseline` | accuracy of always predicting the majority class of that split |
| `balanced_accuracy` | mean per-class recall |
| `macro_precision`, `macro_recall`, `macro_f1` | unweighted mean over the 3 classes |
| `confusion` | rows are truth, columns are prediction, counts of patients |
| `best_epoch` | centralised runs, the epoch whose checkpoint was selected |
| `best_round` | federated runs, the round maximising `val_balanced_accuracy` across clients |
| `training_time_s` | read `training_time_kind` beside it, the two kinds are not the same quantity |
| `training_time_kind` | `compute` for centralised runs, `wall_clock` for federated jobs |

`macro_auc` is NaN whenever a split is missing a whole class, which happens on the
smaller per-hospital validation sets. An AUC over a subset of classes is not
comparable to one over all of them, so it is not produced.

`per_client_metrics.csv` holds the one global model scored on each hospital's own
held-out patients. It is not each hospital's local model.

## How to run it

Score the runs first. This writes the per-patient predictions that everything here
reads:

```bash
python deployment/code/scripts/collect_results.py
```

Then build this folder:

```bash
python deployment/code/scripts/build_final_summary.py
```

| Flag | Effect |
|---|---|
| `--out DIR` | write somewhere other than the default |
| `--results-dir DIR` | read runs from somewhere other than `results/federated/` |
| `--only ID` | build one experiment |
| `--no-client-eval` | skip the per-hospital evaluation, which is the slow part |
| `--pdf` | also write a vector `.pdf` beside every `.png` |

## Where each number comes from

| Output | Read from |
|---|---|
| every headline metric | `<experiment>/predictions_test.csv` |
| ROC, PR and confusion figures | the same file |
| `best_round` | `<experiment>/rounds.csv` |
| `best_epoch` and seed | `test01_centralized/seed_*/results.json` |
| job timing and algorithm | `<experiment>/job.json` |
| per-hospital metrics | the global model scored on `deployment/data/partitions/<p>/<site>/val.csv` |
| cohort tables | `deployment/data/partitions/*/partition.json` and `deployment/data/global/manifest.json` |

Metrics are recomputed from the stored predictions rather than copied from a stored
metric dict, so the confusion matrix, the curves and the table always come from one
array and cannot disagree.
